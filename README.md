# @animatereactnative/curve-loaders

Mathematical curve loading animations for React Native, powered by Skia and Reanimated. 20 particle-trail loaders driven entirely on the UI thread.

## Installation


```sh
npm install @animatereactnative/curve-loaders
```


## Usage


```js
import { multiply } from '@animatereactnative/curve-loaders';

// ...

const result = multiply(3, 7);
```
